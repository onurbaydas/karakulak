# Karakulak

Browser-only Linux distribution: Debian live ISO that boots into fullscreen Firefox
(cage). See README.md for scope and docs/adr/ for decisions.

## Rules

- Follow `.claude/skills/karpathy-guidelines` for every code change: think before
  coding, simplicity first, surgical changes, verifiable goals.
- For questions about the codebase, use `.claude/skills/graphify` (query
  `graphify-out/` first when it exists).
- Record significant design decisions as a new ADR in docs/adr/.
- Commits are signed off (`git commit -s`).
