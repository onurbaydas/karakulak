# Security Policy

Karakulak is in early development and has no stable release yet. Security fixes
go to the `main` branch.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) instead.

Expect a first reply within 7 days. Vulnerabilities in Firefox itself should go
to [Mozilla](https://www.mozilla.org/security/).
