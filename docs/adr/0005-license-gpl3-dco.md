# 0005. GPL-3.0 with DCO

- Status: accepted
- Date: 2026-10-29

## Context

The project should stay open, and contribution should be low-friction.

## Decision

License under GPL-3.0. Contributors sign off commits under the Developer
Certificate of Origin instead of signing a CLA.

## Consequences

- No relicensing without all contributors' consent.
- CI enforces `Signed-off-by` on pull requests.
